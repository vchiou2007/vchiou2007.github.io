Platform View

我理解 Dynatrace 是一個整合式可觀測性平台。

這張平台圖很適合表達我的能力重點：Dynatrace 不只是單一監控畫面，而是把 Infrastructure Observability、 Application Observability、Digital Experience、Log Analytics、Application Security、Software Delivery 與 Business Observability 放在同一個平台中，底層再透過 OneAgent、PurePath、OpenPipeline、Grail、 AutomationEngine、Davis AI 與 Smartscape 串成可分析、可追蹤、可自動化的架構。

Problems I Can Help Solve

我可以用 Dynatrace 能力協助解決的問題

系統慢或不穩定時

  • 用 PurePath 追蹤交易路徑，找出慢在哪一層。
  • 用 host、process、service、database metrics 對照資源瓶頸。
  • 用 user session 與 Appdex 判斷使用者實際感受。

雲端與微服務變複雜時

  • 用 Smartscape 與 Kubernetes monitoring 看服務拓撲。
  • 把 AWS/GCP、container、database 與 application telemetry 放在同一個視角。
  • 透過 logs、metrics、traces 關聯分析問題。

需要自動化營運時

  • 用 Workflows 把監控事件轉成通知、查詢與處理流程。
  • 整合 Slack/Jira，讓問題追蹤更接近實際 IT 運作。
  • 用 DQL task 與 template 產生可重複的處理方式。

需要平台治理時

  • 理解 access tokens、groups、policies 與 account management。
  • 知道如何思考 data privacy、ownership、teams 與 alerting 設計。
  • 能從架構師角度評估 SaaS、Managed 與平台 adoption。
