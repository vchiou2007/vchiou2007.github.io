# 點頭模式 v0.6

同一個測試頁上方選「點頭」。啟動攝影機後按「校準點頭」，正常看著螢幕中央三秒，接著刻意向下點一次並回到原位，用來學習向下方向。這一次校準不會翻頁。

每次「向下點 → 回原位」算一次，數字顯示收到 1、2、3；三次下一頁，兩次等待連續動作間隔到期才上一頁。預設間隔 2 秒，滑桿可調。低頭持續超過 1.5 秒、追蹤失去、側轉過大時取消未完成手勢。切換模式需重新校準，眨眼與點頭不能同時觸發。

點頭角度取自 Face Landmarker 輸出的姿態矩陣；校準取得基準與向下方向，不使用 KIMI 正式頭部控制器。來源：[Google 官方 API 指南](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/web_js)。

測試：六項點頭單元測試，以及模擬攝影機的瀏覽器操作測試：校準 → 三次數字提示 → 第 2 頁 → 切回眨眼。原眨眼數字／節奏瀏覽器測試仍通過。沒有使用真實攝影機或錄製使用者影像；iPad 真實動作辨識與舒適度仍待使用者比較。只控制五張模擬頁。
