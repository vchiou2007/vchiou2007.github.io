# 眨眼翻頁獨立實驗版

版本：POC 0.1。分支：experiment/eye-blink-poc。

保留正式智慧吉他譜及 KIMI 頭部偵測，所有實驗檔案只放在本目錄。目前僅控制五張模擬頁，沒有接上正式歌譜，也沒有發布到正式網站。

## 操作

透過 localhost 或 HTTPS 開啟 index.html。按「啟動攝影機」，允許前鏡頭；先校準，睜眼三秒，再自然眨眼五次。連眨三下下一頁，連眨兩下等待第三下的時間到期後上一頁；單次眨眼忽略。長閉眼、人臉消失與影格中斷取消未完成手勢。翻頁後冷卻一秒。只追蹤一張臉。

初始為 320×240、CPU、目標 24 FPS；可比較 640×480、GPU 與不同門檻。設定變更後重新啟動。切到背景會停止攝影機，返回後需手動啟動。影像只在本機推論，不錄影、不上傳；JSON 匯出僅包含分數、狀態與效能。

## 檔案

| 檔案 | 功能 |
|---|---|
| index.html、styles.css | 實驗操作與五張模擬頁 |
| js/blink-controller.mjs | 眨眼狀態機與唯一手勢出口 |
| js/calibration.mjs | 睜眼基準與五次眨眼校準 |
| js/camera-service.mjs | 前鏡頭、模型、推論與資源停止 |
| js/app.mjs | 實驗介面、模擬翻頁與設定 |
| js/debug-log.mjs | 不含影像的紀錄 |
| vendor/versions.json | 引擎與模型來源、版本及雜湊 |
| tests/controller.test.mjs | 合成分數序列測試 |

## 驗證範圍

2026-10-08：Node 狀態機七項測試全部通過：20 次分散單眨不翻頁、兩眨延遲上一頁、三眨僅下一頁、四眨不連翻、長閉眼取消、人臉失去與返回、單眼眨眼忽略、影格中斷取消。

執行：`node --test tests/controller.test.mjs`。

這些是合成輸入測試，不能代表攝影機辨識成功率。尚待目標 iPad 在約一公尺、實際彈奏坐姿下測試至少十分鐘，檢查自然眨眼誤觸、兩眨／三眨辨識、模型載入、實際 FPS、停止攝影機及背景恢復。Safari 真實相容性與效能尚未確認。iPad 必須用獨立 HTTPS 測試網址；電腦 localhost 無法直接當成 iPad 網址。
