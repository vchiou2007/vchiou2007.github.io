# 詩詞隨身背

正式網址：https://vchiou2007.github.io/poetry-pocket/

在 iPhone Safari 開啟後，從分享選單選「加入主畫面」。首次連線等待「已備妥離線閱讀」，再測試飛航模式。

包含 20 首繁體詩詞、注音、白話說明、搜尋、收藏、名句、背誦與間隔複習。朗讀支援 0.7 至 3 倍速，採整首連續朗讀減少句間停頓；右上角「配色」可切換六種完整主題。

朗讀使用系統中文語音，音色、速度與離線可用性依裝置而異。已保留原先語音選擇規則。逐句高亮取決於語音引擎是否提供文字邊界事件。請在 iPhone 實測。

## 資料與備份

學習資料僅儲存在這個瀏覽器的 IndexedDB，不會上傳到 GitHub。不同網址、瀏覽器或主畫面 App 可能使用不同儲存空間。若從原先試用網址移過來，請先匯出備份，再到本網站匯入。清除網站資料可能遺失紀錄，請定期備份。

## Windows 開發

安裝 Node.js，在這個目錄執行 `node serve.mjs`，用電腦開啟顯示的本機網址。

執行 `node --test tests/*.test.mjs` 可驗證 23 項資料、複習、備份、朗讀狀態與離線快取測試。這些不等於 iPhone 實機測試。

這個目錄就是靜態網站及原始碼，不需要安裝套件或編譯。修改程式後須更新 sw.js 的 VERSION，讓離線快取能換版。GitHub Pages 沿用儲存庫原有發布設定，網站資源與 Service Worker 範圍均位於 /poetry-pocket/。

詩詞來源與版本紀錄見 SOURCES.md 與 SOURCE_REVIEW.json。現代白話說明為學習摘要。

## 快速選讀與兩句練習

首頁新增詩名快速選單與總覽入口；總覽支援搜尋、類型／主題篩選、篇幅排序及最多四首比較。代表作表見 [CATALOGUE.md](CATALOGUE.md)。

名句頁收錄 40 組按語意整理的兩句選摘，可收藏、搜尋及單獨朗讀。練習包含完整閱讀、看上接下、看下想上、兩句都背，答案只在揭曉後顯示。兩句練習不改動全篇複習評分。舊備份與收藏保持相容。
